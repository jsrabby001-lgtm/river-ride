# 리버라이드 · 4대강 완주 노트

한강·낙동강·금강·영산강 자전거길의 주행 기록과 목표 달성률을 관리하는 단일 HTML 앱입니다.

## 앱 열기

**https://jsrabby001-lgtm.github.io/river-ride/**

GitHub Pages 첫 배포가 완료되면 위 주소로 접속할 수 있습니다. 로컬에서는 `index.html`을 브라우저로 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

## 주요 기능

- 4대강 코스 개요도와 선택형 OpenStreetMap 지도
- 수동 주행 거리·시간·메모 기록
- 코스별·전체 목표 달성률 및 누적 거리
- 반복 주행을 완주 진도에서 제외
- 공유용 진도 이미지 PNG 저장
- 코스별 목표 거리 설정
- JSON 기록 백업 및 복원
- 모바일 화면 지원

## 처음 사용하기

1. 자전거길을 선택합니다.
2. 실제로 달린 날짜·거리·시간을 입력합니다.
3. 처음 달린 새 구간만 `코스 완주 진도에 반영하기`를 선택합니다.
4. 기록을 저장하고 코스 진도와 예상 진행 지점을 확인합니다.
5. 중요한 기록은 `백업`으로 파일에 보관합니다.

## 지도와 진도에 관한 주의사항

기본 목표 거리와 경유지 좌표는 여행 계획을 위한 참고값입니다. 지도상의 선은 경유지를 연결한 근사선으로, 실제 자전거도로·내비게이션 경로나 공식 인증센터 데이터가 아닙니다.

진행 위치는 출발점부터 순서대로 주행했다는 가정으로 누적 거리에 따라 추정합니다. GPS 자동 추적과 공식 종주 인증 연동은 지원하지 않습니다. 실제 경로와 인증 요건은 [자전거 행복나눔](https://www.bike.go.kr/)에서 확인하세요.

## 데이터 저장과 개인정보

주행 기록은 현재 브라우저의 localStorage에만 저장하며 GitHub에 업로드하지 않습니다. 다른 기기·브라우저와 자동 동기화하지 않습니다. 사이트 데이터를 지우면 기록이 사라지므로 JSON 백업을 권장합니다.

로컬 HTML 파일과 GitHub Pages 사이트의 저장 공간은 다릅니다. 로컬 기록을 옮기려면 기존 앱에서 백업한 JSON을 배포된 앱에서 불러오세요. 백업 복원은 기존 기록을 교체하므로 먼저 백업하세요. 개인 주행 기록이 담긴 JSON 파일은 공개 저장소에 커밋하지 마세요.

## 네트워크 및 지도 출처

계산·기록·개요도·이미지 내보내기는 외부 라이브러리 없이 작동합니다. `실제 지도 보기`를 선택할 때만 인터넷을 통해 Leaflet 1.9.4와 OpenStreetMap 지도를 불러옵니다.

- 지도 라이브러리: [Leaflet](https://leafletjs.com/)
- 지도 데이터: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)
